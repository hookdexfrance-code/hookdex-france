Politique de confidentialité — HookDex France

Dernière mise à jour : à compléter par vous-même avant publication.

Quelles données HookDex utilise-t-il ?

HookDex France est une application de carnet de pêche. Elle peut vous demander d'utiliser les données suivantes, uniquement avec votre action volontaire :

  • Position GPS : utilisée uniquement si vous appuyez sur « Utiliser ma position » lors de l'ajout d'une prise ou du lancement d'une sortie. Vous pouvez aussi saisir des coordonnées manuellement, ou ne rien renseigner du tout.
  • Photos : uniquement celles que vous prenez ou sélectionnez vous-même pour illustrer une prise.
  • Informations que vous saisissez : espèce, date, heure, taille, poids, météo, matériel utilisé, remarques, etc.

Où ces données sont-elles stockées ?

Toutes les données que vous saisissez dans HookDex (prises, sorties, photos, position GPS) sont stockées uniquement sur votre appareil, dans le stockage local de votre navigateur. Elles ne sont jamais envoyées à un serveur, à nous, ni à un tiers.

Partage de données

HookDex ne collecte, ne transmet ni ne vend aucune donnée personnelle à des tiers. La seule situation où une donnée peut quitter l'application est lorsque vous choisissez volontairement d'ouvrir une position GPS dans Google Maps (ou une autre application de cartographie installée sur votre téléphone) : dans ce cas, les coordonnées sont transmises à cette application via une action que vous initiez explicitement.

Fonctionnalités nécessitant une connexion internet

L'affichage de la carte interactive (fonds de carte OpenStreetMap) nécessite une connexion internet. Le reste de l'application fonctionne hors ligne.

Suppression de vos données

Vous pouvez à tout moment exporter vos données (JSON ou CSV) ou les supprimer intégralement depuis les Paramètres de l'application. Désinstaller l'application ou vider les données du navigateur supprime également toutes les données stockées localement.
